## What changed and what remains necessary

| Previous overhead | Lightweight replacement / retained thesis-quality purpose |
|---|---|
| G0-G6 chain, gate dashboards and release boards | Four research phases: selection, annotation, evaluation and freeze; short dated records by the researcher. |
| Multiple approval roles, assignment workflows, signatures and attestations | No mandatory approval staffing or forms. Record researcher/date/evidence references so work is attributable. |
| Mandatory independent annotation approval and agreement threshold | Researcher verifies every included question/answer/evidence location. Independent review is optional; disclose solo review and do not claim agreement without measurements. Existing pilot reviews are preserved. |
| Full-history/security clearance and retrospective exposure dossiers for every candidate | Basic safety check for the actual selected snapshot/file scope; investigate relevant known issues or exclude affected scope. Record limitations, never infer clean results from missing evidence. |
| Extensive handling-control packets | Concise local handling note, appropriate access, sensitive-file exclusion and license notices. No routine ACL exports/backup attestations; actual applicable handling conditions still matter. |
| Clearance matrix and ongoing evidence closure for unused repositories | NOT SELECTED FOR THESIS SCOPE; archived evidence only. Revisit only if scope changes. |
| Multi-stage freeze/release approval | Version identifier, artifact hashes and change log, linked to fixed evaluation inputs and reproducible runs. Distribution rights remain separate; no release occurs here. |

Research controls retained: exact snapshots, license/notices, basic data safety, traceable evidence and source spans, source-grounded answers, documented validation, fixed evaluation inputs and metrics, failures/error analysis, exposure/claim limitations, reproducible experiment records and immutable version/hash history. No retrieval score determines whether valid questions should be removed.
